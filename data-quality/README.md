# Qualidade de dados

Regras de qualidade devem ser automatizadas e mensuráveis.

Dimensões mínimas:
- completude;
- unicidade;
- integridade referencial;
- validade de domínio;
- consistência temporal;
- ausência de duplicidade em operações idempotentes.

Falhas devem produzir evidência reproduzível, sem expor conteúdo sensível.
