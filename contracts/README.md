# Contratos

Define contratos de dados compartilhados entre produtores e consumidores.

Cada contrato deve declarar:
- nome e versão;
- proprietário;
- campos, tipos e nulabilidade;
- chaves e regras de unicidade;
- compatibilidade;
- estratégia de evolução;
- exemplos exclusivamente sintéticos.

Mudança incompatível exige nova versão ou migração coordenada.
