# Segurança de dados

Este repositório não é um armazenamento de dados operacionais.

## Proibido versionar

- dados pessoais ou confidenciais;
- bancos reais e snapshots;
- dumps/backups;
- credenciais, tokens e chaves;
- exportações de DEV/STG/PROD;
- arquivos contendo payloads reais de integrações.

## Permitido

- schemas e contratos;
- exemplos mínimos sintéticos;
- scripts sem segredos;
- hashes, métricas e evidências não sensíveis;
- documentação de políticas.

Em caso de dúvida, tratar o conteúdo como sensível e não versionar.
